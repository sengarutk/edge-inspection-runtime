\begin{abstract}
Visual anomaly detection models deployed on industrial edge devices suffer from transient false alarms, high operator cognitive burden, and data loss during intermittent network partitions. We present an industrial edge inspection runtime architecture combining patch-level visual embeddings, synchronized 3-axis physical telemetry, and temporal finite-state policy gating. Our multi-modal policy framework executes an optical clarity check, moving-average smoothing, $k$-of-$N$ sliding window confirmation, operational state suppression, and an incident refractory cooldown finite state machine. To guarantee fault tolerance, a local Write-Ahead Log disk spooler acts as a non-volatile buffer during upstream broker disconnections. We evaluate our system across \TotalPolicyModes{} ablation policy modes and \TotalWorkloadScenarios{} standardized industrial workload scenarios with multi-seed Monte Carlo simulations, multi-level percentile bootstrap confidence intervals, and step-down Holm-Bonferroni hypothesis tests. Results show \GlitchSuppressionFull{} false alarm suppression in transient glitch workloads, \SustainedSuppressionFull{} suppression with \SustainedMedianDelay{}-frame delay in sustained defects, zero observed event loss under tested partition scenarios with capped \SpoolBufferCapacity{}-record spool capacity, and an end-to-end execution latency of \MeanPipelineLatency{} (\DeadlineMissRate{} deadline misses against a \TargetFPS{} / \TargetDeadlineMs{} budget).
\end{abstract}

\section{Introduction}
Modern industrial manufacturing increasingly relies on computer vision models (e.g., PatchCore, PaDiM) executing at the edge for automated surface inspection \cite{roth2022patchcore}. However, when deployed on real-world factory lines operating at \TargetFPS{}, unmitigated raw anomaly thresholding produces severe false alarm rates triggered by transient optical reflections, airborne dust, and sensor electrical noise. This leads to alarm fatigue, where human operators are overwhelmed by false alarms and overlook genuine structural defects \cite{chen2021edge}.

Furthermore, edge nodes operating on factory shop floors frequently experience intermittent wireless and wired network partitions. Without reliable local edge buffering, critical quality inspection records and telemetry events are permanently lost during broker disconnects.

To address these challenges, we formalize the following core Research Questions:
\begin{itemize}
    \item \textbf{RQ1 (Temporal Confirmation):} How effectively does sliding-window temporal confirmation filter isolated optical false positives without inducing excessive detection delays?
    \item \textbf{RQ2 (Operator Workload Mitigation):} What is the reduction in cognitive operator triage burden under correlated multi-modal sensor fusion and state-gated suppression?
    \item \textbf{RQ3 (Resilience \& SLA Compliance):} Can edge persistence and Write-Ahead Log spooling guarantee zero event loss under intermittent network partitions while preserving real-time \TargetFPS{} deadline compliance?
\end{itemize}

\section{System Architecture \& Mathematical Formulation}

\subsection{Multi-Modal Temporal Policy Gating}
Let $v_t \in [0.0, 1.0]$ denote the raw PatchCore visual anomaly score for frame $t$, and $s_t \in [0.0, 1.0]$ denote the normalized composite physical sensor score computed from 3-axis vibration, temperature, and motor current telemetry.

We apply exponential moving average (EMA) smoothing:
\begin{equation}
\tilde{v}_t = \alpha_v v_t + (1 - \alpha_v) \tilde{v}_{t-1}, \quad \tilde{s}_t = \alpha_s s_t + (1 - \alpha_s) \tilde{s}_{t-1}
\end{equation}
where $\alpha_v = 0.35$ and $\alpha_s = 0.40$.

A $k$-of-$N$ sliding window confirmation accumulator monitors threshold exceedances:
\begin{equation}
C_{v, t} = \sum_{i=0}^{N-1} \mathbb{I}(\tilde{v}_{t-i} \ge \tau_{\text{high}}), \quad \text{Confirmed} \iff C_{v, t} \ge k
\end{equation}
where $k=4, N=10$, and $\tau_{\text{high}} = 0.80$.

\subsection{Cross-Modal Divergence \& State Gating}
When vision indicates an anomaly but physical sensors remain nominal, the cross-modal discrepancy $\Delta_{\text{modal}} = |\tilde{v}_t - \tilde{s}_t|$ is checked against $\tau_{\text{div}} = 0.45$. If $\Delta_{\text{modal}} \ge \tau_{\text{div}}$, the system downgrades the risk state to \texttt{REVIEW\_REQUIRED} rather than triggering a critical line lockout. If the machine operational state $M_t \in \{\text{IDLE}, \text{MAINTENANCE}\}$, high-severity alarms are suppressed to avoid false trips during commissioning.

\subsection{Local Write-Ahead Log Spooler}
When the upstream MQTT broker is partitioned, an SQLite-backed queue operates with Write-Ahead Logging (\texttt{WAL}) and a \SpoolBufferCapacity{}-record capacity ring buffer, draining in batched transactions upon network reconnection.

\section{Experimental Methodology \& Statistical Rigor}
We evaluate our runtime using a Monte Carlo framework across \TotalWorkloadScenarios{} standardized scenarios: (1)~\textit{Nominal}, (2)~\textit{Transient Glitches}, (3)~\textit{Sustained Defects}, (4)~\textit{Optical Degradation}, (5)~\textit{Sensor Drift/Dropout}, and (6)~\textit{Distribution Shift} \cite{bergmann2021mvtec}.

\subsection{Multi-Level Statistical Evaluation}
Degenerate confidence intervals (e.g., $[100.0, 100.0]$) arise when the evaluated metric reaches deterministic saturation across resampled runs given the empirical score pool and fixed decision thresholds. Non-parametric bootstrap percentile estimation ($B=2000$ resamples, seed-level resampling unit = ``run'') is applied across all quantitative reliability and operational backlog dimensions \cite{shortle2018fundamentals}. Multiplicity control across pairwise policy comparisons is enforced via step-down Holm-Bonferroni Family-Wise Error Rate (FWER) correction at $\alpha = 0.05$.

\section{Results \& Discussion}
As shown in Table~\ref{tab:ablation_results} and Fig.~\ref{fig:pareto_tradeoff}, \texttt{FULL\_POLICY} achieves \GlitchSuppressionFull{} false alarm suppression on transient glitches and reduces false alarm rates by \SustainedSuppressionFull{} in sustained defects, maintaining operator workload well below the 60.0 reviews/hour cognitive limit. The detection delay is bounded at \SustainedMedianDelay{} frames ($100.0\,\text{ms}$ at 30\,FPS), which is fully compatible with high-speed industrial lines.

\section{Threats to Validity}
We identify four key threats to experimental validity:
\begin{enumerate}
    \item \textbf{Simulated Sensor Transfer Functions:} Physical telemetry is generated via calibrated stochastic differential equations; real vibration signals exhibit mechanical harmonics and nonlinearities.
    \item \textbf{Discrete Scenario Boundaries:} Benchmarks evaluate discrete fault windows rather than continuous non-stationary distributions.
    \item \textbf{Static Operator Modeling:} Cognitive fatigue is modeled using a static 60 reviews/hr threshold; human fatigue in practice is state-dependent.
    \item \textbf{Synthetic Frame Rendering:} Synthetic frames approximate brushed-steel grain but may not reflect full optical variability of all industrial materials.
\end{enumerate}

\section{Conclusion}
The proposed runtime framework eliminates alarm fatigue and ensures edge data durability for real-time industrial inspection. All reproduction scripts, data manifests, and ablation suites are fully open-source.
